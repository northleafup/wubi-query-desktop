## Purpose

提供用户可交互的五笔查询界面，包含搜索输入、结果展示和字根图片渲染，使用纯 HTML/CSS/JS 实现。

## ADDED Requirements

### Requirement: 搜索输入框
系统 SHALL 提供一个文本输入框，用户可输入一个或多个汉字进行查询。支持回车键触发查询和点击"查询"按钮触发查询。

#### Scenario: 输入汉字后回车查询
- **WHEN** 用户在输入框中输入"五笔"并按回车
- **THEN** 系统调用后端查询接口，返回并展示"五"和"笔"的查询结果

#### Scenario: 点击查询按钮
- **WHEN** 用户在输入框中输入汉字后点击"查询"按钮
- **THEN** 系统执行查询并展示结果

#### Scenario: 输入为空时查询
- **WHEN** 用户未输入任何内容触发查询
- **THEN** 系统不执行查询，结果区域保持空白

### Requirement: 结果表格展示
系统 SHALL 以表格形式展示查询结果，包含以下列：序号、汉字（大号字体）、基本信息（拼音+笔画）、五笔全码、简码/容错码、字根拆解（GIF 图片）。

#### Scenario: 展示多字查询结果
- **WHEN** 查询输入包含 3 个汉字且全部在数据集中
- **THEN** 表格显示 3 行数据，每行包含该汉字的全部信息

#### Scenario: 部分汉字无结果
- **WHEN** 查询输入包含 3 个汉字，其中 1 个不在数据集中
- **THEN** 表格只展示有结果的 2 行数据

#### Scenario: 字根 GIF 图片正确显示
- **WHEN** 查询结果的汉字有对应的字根 GIF 图片
- **THEN** "字根拆解"列显示 GIF 动画图片，图片高度适配行高

### Requirement: 标题栏信息显示
系统 SHALL 在顶部显示应用名称"五笔编码查询"、已加载的汉字数量、ESC 退出提示。

#### Scenario: 数据加载完成后显示统计
- **WHEN** 应用启动且数据加载成功
- **THEN** 标题栏显示"N 个汉字已加载"（N 为实际加载的汉字数量）

### Requirement: 中文渲染无乱码
系统 SHALL 在 macOS、Windows、Linux 三平台上正确渲染所有中文字符，不出现乱码或方框。

#### Scenario: macOS 上中文正常显示
- **WHEN** 在 macOS 上运行应用并查询汉字
- **THEN** 所有中文字符（包括标题、表格内容、输入框）正常显示，无乱码

#### Scenario: Windows 上中文正常显示
- **WHEN** 在 Windows 上运行应用并查询汉字
- **THEN** 所有中文字符正常显示

#### Scenario: Linux 上中文正常显示
- **WHEN** 在 Linux (Ubuntu) 上运行应用并查询汉字
- **THEN** 所有中文字符正常显示
