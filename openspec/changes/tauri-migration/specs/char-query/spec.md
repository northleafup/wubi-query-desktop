## Purpose

提供汉字五笔编码查询功能，接受用户输入的汉字，返回结构化的查询结果。

## ADDED Requirements

### Requirement: 单字查询
系统 SHALL 接受单个汉字输入，返回该汉字的完整五笔编码信息，包括全码、简码、拼音、笔画数、字根拆解和图片路径。

#### Scenario: 查询存在的汉字
- **WHEN** 前端发送查询请求，输入为单个汉字（如"五"）
- **THEN** 后端返回该汉字的完整结构化数据（五笔全码、简码、拼音、笔画、字根拆解 GIF 路径）

#### Scenario: 查询不存在的汉字
- **WHEN** 前端发送查询请求，输入为不在数据集中的汉字
- **THEN** 后端返回空结果列表

### Requirement: 多字批量查询
系统 SHALL 接受包含多个汉字的字符串输入，按顺序提取每个汉字并逐一查询，返回所有匹配结果的列表。

#### Scenario: 输入多个汉字
- **WHEN** 前端发送查询请求，输入为"北京"
- **THEN** 后端分别查询"北"和"京"，返回包含两个汉字数据的数组

#### Scenario: 输入包含重复汉字
- **WHEN** 前端发送查询请求，输入包含重复汉字（如"好好"）
- **THEN** 后端去重后只返回一次"好"的查询结果

#### Scenario: 输入包含非汉字字符
- **WHEN** 前端发送查询请求，输入混合了汉字和英文/数字/标点
- **THEN** 后端只提取汉字部分进行查询，忽略非汉字字符

### Requirement: 查询结果结构
系统 SHALL 以 JSON 格式返回查询结果，每个结果包含以下字段：character（汉字）、wubi_code（全码）、simple_codes（简码数组）、pinyin（拼音）、strokes（笔画数）、segments（字根拆解）、image_path（GIF 图片路径）。

#### Scenario: 返回结果可被前端直接渲染
- **WHEN** 后端返回查询结果
- **THEN** 结果格式为 JSON 数组，每个元素包含上述全部字段，前端可直接用于表格渲染
